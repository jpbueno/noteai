# NoteAI 7 — Meetings and AI Solutions Architect

## Scope

The primary macOS app focuses on recording/transcription and the live AI Solutions Architect. It retains automatic detection, transcript import, speaker context, meeting summaries/editing, history/search, export, and read-aloud.

Standalone notes, T5T, tasks, to dos, the general AI assistant, and external work-activity connections are removed from the macOS interface and implementation. Action items within meeting summaries remain part of the meeting record.

## Data compatibility

The primary app remains `com.noteai.app` and uses the existing `NoteAI` storage namespace and Keychain service. Existing meetings and provider keys remain accessible. Retired SQLite tables and their rows are left untouched; the focused app no longer creates or migrates them. Keep normal backups for access to archived legacy records.

The separate v6 transcript-import target keeps its existing identity and isolated namespace. The web source and deployment remain permanently retired under JPB-191.

## Installation

Build the `NoteAI` scheme and replace the installed app only after any active recording is finished. Do not interrupt recording to activate the update. The existing app bundle can be kept as a rollback copy; no destructive data migration is needed.

## Verification

Use the focused persistence/data-preservation tests and the retained recording, AI SA, transcript, summary and export regressions. Run the full `NoteAI` Xcode test scheme and build, then verify PR and post-merge checks. Record actual command/results in JPB-26.
